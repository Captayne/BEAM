Beam! and what it is 

Beam is a filsharing application to share from small to enormous files from smartphone to smartphone using the torrent network.
📤 How to Send
To share file(s) pick Beam! using the standard sharing mechanism. For large videos you can choose to reduce the quality/size first. 
Beam! creates a small .beam file which contains the unique HASH code for identification — send this to a friend via any app (WhatsApp, email, …) again using the standard sharing mechanism. 

The sending smartphone needs to be awake and online to be able to send/seed the data, so that the receiver(s) can download it from your phone.

🗓 Send Chronology — back up a whole event in one gesture
This is the easy way to move an entire trip, party or day from your phone to your PC (your permanent archive).
Instead of picking hundreds of files, you just mark the START and the END of the event:
• In your gallery, select the FIRST photo (e.g. at the airport) and the LAST one (e.g. back in the garden) and share them to Beam!.
• On the "Ready to send" card, tick "Chrono". Beam then takes the oldest and newest of your marked files as the time span and automatically adds EVERYTHING in between — photos, videos, even WhatsApp pictures and screenshots from those days.
• The card shows exactly what was found (photos, videos, and where they came from) before you press BEAM! it — so you can check the span is right.
Chronology always sends your ORIGINALS, untouched — so encryption and "Video quality" are switched off (greyed out) in this mode. Tip: keep the phone charging, large events take a while.

📥 Receive
Open the received ########.beam file using the beam!-app. 
Beam displays the download activity-card and the file downloads automatically: 
photos & videos go to your gallery, everything else to Download/Beam.

🎛 Icons inside an activity-card:
📋  copy magnet link, to be used in other torrent apps.
(V) Re-Share the sharing, to invite more people to download the file.
(R) Reconnect/Retry, eg. if network has changed
⏳ file(s) is not ready for anything.
▶  play / open a file. Single uncrypted videos can be streamed during download
🗑  delete everything, including received(!) files.
✕  remove activity-card only, keep files.

🔗 Settings/Trackers:
Trackers help sender and receiver find each other. You can edit the tracker list under Settings; sender and receiver must use the same tracker (the defaults work).

🚀 Faster & more reliable
- Best speed: have both phones on the same 5 GHz Wi-Fi (or use one phone's hotspot and connect the other to it) — this avoids the router bottleneck.
- Over mobile data a direct connection isn't always possible (carrier NAT). Same Wi-Fi is the most reliable.
- Let Beam run freely: turn OFF battery optimization for Beam. On Xiaomi/MIUI also enable "Autostart".
- On mobile data: disable "Data Saver" for Beam (or allow unrestricted data), otherwise transfers get throttled.
- Keep the sending phone awake/charging until the receiver is done.

You can keep compressed videos if you like, then they are not deleted after the activity-card is deleted.
